# NNN 기능 이름

> Codex 위임용 구현 계획. 이 문서만 보고 구현할 수 있어야 한다. 막히면 추측하지 말고 멈추고 보고한다.

## 1. 목표

한두 문장. 무엇을 만드는지, 어떻게 쓰는지.

| 상황 | 입력 | 출력 | 종료 코드 / 결과 |
|---|---|---|---|
| | | | |

## 3. 데이터 형식

저장하거나 주고받는 데이터가 있을 때만 쓴다. 필드, 타입, 설명.

|---|---|---|
| | | |

## 5. 완료 조건

명령 한 줄로 확인되는 것만 쓴다.

- [ ] `<테스트 명령>`이 전부 통과한다.
- [ ] 2번 표의 모든 행을 테스트가 하나 이상 확인한다.
- [ ] 4번 표에 없는 파일은 바뀌지 않았다 (`git status`로 확인).

## 6. 건드리지 말 것

- 계획에 없는 파일, 요청에 없는 기능.
- 외부 의존성 추가, `.env` 파일 생성.
- 이 계획 파일 자체.
